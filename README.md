# PayLink — Fintech Landing Page

A modern fintech concept designed to simplify online payment collection for businesses through shareable payment links.

## Overview

PayLink is a conceptual B2B fintech product that enables businesses to request and collect payments without needing a fully developed e-commerce website.

The project focuses on creating a clear, trustworthy, and conversion-oriented landing page that communicates the product's value and simplifies the user journey.

## Project Goals

- Communicate the product's value proposition clearly.
- Build trust through a consistent visual identity.
- Create a modern and professional fintech experience.
- Guide visitors toward creating a payment link or getting started.

## Target Audience

Small and medium-sized businesses, including:

- Freelancers and independent professionals
- Consulting and marketing agencies
- Service-based businesses
- Small businesses accepting online payments

## Design Process

- Product definition and target audience
- Visual direction and brand identity
- Color palette and typography
- UI design and layout exploration
- Responsive design considerations

## Visual Identity

The visual direction combines a bold, minimal aesthetic with a professional fintech feel.

- **Primary colors:** Yellow, black, and supporting neutral tones
- **Design approach:** Clean, modern, and conversion-focused
- **Visual concept:** A recognizable chain-inspired logo representing connected payments and seamless transactions

## Tools

- Figma
- Figma Variables and Components

## Project Status

Currently in progress.
